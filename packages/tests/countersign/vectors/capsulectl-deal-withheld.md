# capsulectl-deal-withheld.json

The withheld bundle that `capsulectl deal report --deal ID --bundle FILE --withheld`
writes for the buyer's book of an agreed x-deal-v1 deal, taken unchanged from
evidencebook at 63f2d61 (capsulectl's `withheldForm`,
`capsulectl/internal/deal/deal_v1_countersign.go`). It states
`completeness.payloads_mode: "selected"` and carries no `disclosures`.

How it was written: in an evidencebook checkout at 63f2d61, a throwaway test in
`capsulectl/internal/deal/` ran the package's own `agreedBoth(t, offerTo)`
handshake and its `withheldV1` helper (which runs the `deal report --bundle
FILE --withheld` command) and copied the file out:

```go
h := agreedBoth(t, offerTo)
raw, _ := os.ReadFile(withheldV1(t, h))
os.WriteFile(os.Getenv("DUMP_WITHHELD"), raw, 0o600)
```

All keys in it are generated by that test run; nothing names a real party.
